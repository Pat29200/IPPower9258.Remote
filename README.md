# IPPower9258.Remote

Android application for remote control of the Aviosys IP Power 9258.

## Features

- Control the four power outlets individually.
- Display the current state of each outlet.
- Configure the IP address and connection settings of the IP Power 9258.
- Works over a local Wi-Fi network.
- Can be used remotely through a VPN such as WireGuard.

## Download

The latest Android APK is available in the **Releases** section of this repository.

Download the file:

`IPPower9258.Remote-v0.3.1.apk`

## Installation on Android

This application is distributed directly through GitHub and is not currently distributed through the Google Play Store.

After downloading the APK, Android may ask you to authorize the installation of applications from your browser or file manager.

### Google Play Protect warning

During installation, Google Play Protect may display a warning such as:

> "Play Protect hasn't seen this app from this developer before."

This warning can occur because IPPower9258.Remote is distributed independently and is not installed from the Google Play Store.

If the APK was downloaded from the official GitHub Releases page of this repository, you can choose **Install anyway** to continue the installation.

Google Play Protect may then analyze the application before completing the installation.
